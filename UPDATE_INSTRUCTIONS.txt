HOW TO UPDATE
1. Unzip this folder on your computer.
2. Open your private GitHub repository: berri97/allround-practice-generator
3. Use Add file -> Upload files to upload BOTH Python files into the main folder.
4. Commit the changes, replacing the files with the same names.
5. Streamlit Community Cloud should automatically redeploy the updated app.
6. Open your website, generate a NEW case and download the instructor TXT and JSON.
   Previously downloaded reports will not be changed.
